# Project roadmap

Use this page to see which models design-generators plans to port, in what order, and which ones already exist as packages. Live status such as priority, progress, and weight availability lives in each model's issue; this page changes only when a target is added or its scope changes.

## Execution order

1. Establish the shared `laygen` library and implement LayoutDM, because later layout packages depend on the shared output and pipeline contracts.
2. Implement Layout-Corrector together with LayoutGAN++, LACE, LayoutFlow, LayoutFormer++, and LayoutDiffusion, which form the next shared layout-package group.
3. Implement Coarse-to-Fine, Parse-Then-Place, and Lay-Your-Scene.
4. Continue with the remaining layout packages and multimodal or language-model recipe packages listed below.
5. Add package-local training and conversion workflows for targets whose planned scope requires repository training.
6. Add external-LLM layout-agent packages independently when their model plans are ready.
